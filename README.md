This project demonstrates my skills in deep learning and NLP through building an LSTM-based news classifier using TensorFlow and Keras. I combined article titles and text, implemented text cleaning and stopword removal, and converted text into tokenised, padded sequences, fitting the vocabulary on training data only. I built a neural network with word embeddings, an LSTM layer and dropout, and used validation monitoring and early stopping to manage overfitting. The model achieved 94.59% accuracy on 17,885 held-out articles, with precision and recall of approximately 0.94–0.95 across both classes. I also interpreted learning curves, classification reports and a confusion matrix, while recognising that strong test performance does not establish reliability across different news sources, topics or time periods.

*The dataset is not provided because it is too large to be uploaded to Github.
